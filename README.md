# PA03 - Computación Paralela y Distribuida

## Descripción
Simulador académico para analizar un sistema paralelo y distribuido orientado al procesamiento masivo de datos ambientales en la Sierra Central.

El proyecto evalúa:

- scheduling y balanceo de carga;
- comunicación distribuida;
- sincronización y exclusión mutua;
- condiciones de carrera;
- prevención de deadlock;
- reintentos e idempotencia;
- replicación, quórum y CAP;
- escalabilidad con múltiples workers.

## Archivos
- `PA03_simulador_ambiental.html`: simulador interactivo.
- `PA3_Chamorro_Juan.docx`: informe técnico del Producto Académico 03.

## Ejecución
Abrir `PA03_simulador_ambiental.html` en cualquier navegador web moderno. No requiere instalación adicional.
